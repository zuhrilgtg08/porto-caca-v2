# Cantika Portofolio

Cantika Portofolio adalah website portofolio yang dibangun menggunakan Next.js, Tailwind CSS, dan Framer Motion. Memungkinkan developer untuk menampilkan proyek, keterampilan, dan blog mereka dengan cara yang menarik secara visual.

## Fitur

- Desain responsif menggunakan Tailwind CSS
- Animasi halus dengan Framer Motion
- Dukungan mode gelap
- Komponen modular dan dapat digunakan kembali
- Mudah untuk dikustomisasi

## Penggunaan
Proyek Cantika Portofolio terstruktur dengan baik untuk intuitif dan mudah dinavigasi.

Dengan memahami struktur dan komponen Cantika Portofolio, Anda dapat dengan mudah menyesuaikan dan memperluas proyek sesuai kebutuhan Anda.
